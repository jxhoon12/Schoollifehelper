# Schoollifehelper
중학생을 위한 학교 생활 도우미 # SchoolLife Helper

모바일 대응 학교생활 관리 + 게임형 웹앱.

## 포함 기능
- 이메일/비밀번호 회원가입 및 로그인 (브라우저 로컬 저장, PBKDF2 해시)
- 할 일, 시간표, 시험 D-Day, 5분 단위 집중 타이머(5~120분)
- 공부 시합, 숫자 기억하기, 가위바위보, 반응속도 게임
- 캐릭터 꾸미기: 얼굴, 헤어, 눈, 눈 색, 머리 색, 의상, 신발, 스타일
- 캐릭터 뽑기: 1회 30P, 기본/레어/에픽/신화/전설/고대/초월 등급별 아이템 획득 및 보관함에서 착용, 중복 아이템은 10P 환급
- 공부 타이머 완료 시간 누적: 공부 10분마다 게임 쿠폰 1개 지급(5분 단위 타이머 완료 시간 기준)
- 게임 쿠폰: 미니게임 1회 시작 또는 디펜스 전투 시작 시 1개 사용, 쿠폰이 없으면 시작 차단
- 포인트 상점과 배경 꾸미기
- 분실물 찾기, 교실 찾기
- 과목 디펜스: 수학/과학/영어/국어/역사/사회/체육 무기, 7개 등급, 포탑 배치와 웨이브
- PWA 모바일 설치 지원

## 실행
`index.html`을 HTTPS 호스팅(GitHub Pages 등)에 올려 사용하세요. 로컬 파일(file://)에서는 브라우저 보안 정책에 따라 Web Crypto 로그인 기능이 제한될 수 있습니다.

## 중요한 제한
로그인과 데이터는 현재 사용하는 브라우저의 localStorage에만 저장됩니다. 실제 이메일 인증, 비밀번호 재설정, 여러 기기 동기화, 친구 간 실시간 대결, 학교 전체 분실물 공유를 하려면 Firebase/Supabase 같은 백엔드 연결이 추가로 필요합니다. 이 앱에 실제 계정 서버가 연결된 것은 아닙니다. 비밀번호는 브라우저에 평문으로 저장하지 않고 PBKDF2 해시로 저장합니다.


## 마스터 계정
- 아이디: `master`
- 비밀번호: `111`
- 마스터 로그인은 로그인 탭에서 사용할 수 있으며, 로그인 화면에는 마스터 자격 증명을 안내하지 않습니다.
- 마스터 권한: 무제한 포인트, 기존 상점 아이템/배경 전체 보유 및 무료 구매, 관리자 콘솔, 로컬 사용자 목록 조회·데이터 초기화·계정 삭제, 사용자 포인트 지급.

## 보안 범위
이 프로젝트는 프런트엔드 데모이며 마스터 인증도 브라우저 코드에 포함된 방식입니다. 따라서 공개 서비스에서 안전한 관리자 인증으로 사용하면 안 됩니다. 실제 서비스로 배포하기 전에는 서버 측 인증/권한 검증, 데이터베이스, 감사 로그를 구현해야 합니다. 관리자 사용자 관리와 포인트 지급은 동일 브라우저의 localStorage에 있는 계정에 한정됩니다.
